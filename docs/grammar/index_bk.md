# Grammar

Welcome to the English grammar section. Each topic is a standalone lesson
written in Markdown, with explanations, tables, examples, and common mistakes.

## Topics

- [Verb Tenses](./tenses) — the 12 English tenses and how to use them
- [Articles](./articles) — *a*, *an*, *the*, and the zero article
- [Sentence Structure](./sentence-structure) — clauses and the four sentence types

::: tip How this site is organized
Each lesson follows the same pattern: **explanation → forms → examples →
common mistakes**. Use the search box (press <kbd>Ctrl</kbd> + <kbd>K</kbd>)
to find any topic instantly.
:::

## Suggested learning order

1. **Verb Tenses** — the backbone of English grammar
2. **Articles** — small words, frequent mistakes
3. **Sentence Structure** — how to combine ideas correctly
